# B.Com Semester 6 Learning Portal

Dynamic and optimized learning portal for B.Com Semester 6 students.

## Features
- Fully reusable data structure
- No repetition
- Dynamic rendering
- Subject filtering
- Professional UI
- GitHub Pages ready

## Deployment
1. Upload files to GitHub repository
2. Go to Settings → Pages
3. Select branch → main
4. Save
5. Your portal is live
